{%- comment -%} Safe HTML helpers for scripts that build markup from external API data (research panel sources). Usage: {% include components/atoms/safe-html.html %} once, before scripts that call: iplEsc(text) → text with & < > " ' escaped (for element content and attribute values) iplText(html) → plain text of an HTML snippet (e.g. Wikipedia search snippets) iplUrl(url) → the URL escaped for an attribute if it is http(s), otherwise "#" {%- endcomment -%}
