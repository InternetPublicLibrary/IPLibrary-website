{%- comment -%} Real resources (spec 002) — collects curated resources under a _data node, skipping generated placeholders (example.com) and keeping one entry per resource name. Usage: {% assign topic_data = site.data[page.lang][page.data_folder] %}{% include components/atoms/real-resources.html node=topic_data %} Sets: real_resources (array of {name, url, description, …}), real_resource_total (number) Accepts a node whose values are resource lists (category files) or folders of lists (subcategories). {%- endcomment -%} {%- assign real_collected = '' | split: '' -%} {%- for entry in include.node -%} {%- assign entry_value = entry[1] -%} {%- if entry_value.first.url or entry_value.first.name -%} {%- for r in entry_value -%}{%- if r.url -%}{%- unless r.url contains 'example.com' -%}{%- assign real_collected = real_collected | push: r -%}{%- endunless -%}{%- endif -%}{%- endfor -%} {%- else -%} {%- for file in entry_value -%} {%- if file[1].first.url -%}{%- for r in file[1] -%}{%- if r.url -%}{%- unless r.url contains 'example.com' -%}{%- assign real_collected = real_collected | push: r -%}{%- endunless -%}{%- endif -%}{%- endfor -%}{%- endif -%} {%- endfor -%} {%- endif -%} {%- endfor -%} {%- assign real_resources = '' | split: '' -%} {%- assign real_groups = real_collected | group_by: 'name' -%} {%- for g in real_groups -%}{%- assign real_resources = real_resources | push: g.items.first -%}{%- endfor -%} {%- assign real_resource_total = real_resources.size -%}
